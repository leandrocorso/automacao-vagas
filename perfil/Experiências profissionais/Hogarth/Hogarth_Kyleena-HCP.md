# Kyleena Patient

**Cliente:** Bayer (USA)
**Contratante:** Hogarth

## Sobre o projeto

Kyleena é um dispositivo intrauterino (DIU) usado para controle de natalidade. A ajuda a prevenir a gravidez, oferecendo uma opção contraceptiva eficaz e de longa duração.
Site direcionado à HCP (HealthCare Professionals), sigla em inglês para "profissionais de saúde".
