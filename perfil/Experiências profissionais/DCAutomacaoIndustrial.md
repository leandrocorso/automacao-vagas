## Sobre o projeto

Desenvolvimento do DC-MES, uma plataforma completa de Manufacturing Execution System (MES) e telemetria OEE (Overall Equipment Effectiveness) voltada para teares industriais planos. O sistema permite o monitoramento em tempo real do chão de fábrica, controle de processos e indicadores de eficiência.

## Principais Responsabilidades e Realizações

- **Arquitetura Fullstack:** Construção da plataforma web e interfaces de CRUD utilizando Next.js, React, TypeScript, Material UI e Tailwind CSS, garantindo uma interface responsiva e de alta performance.
- **Monitoramento em Tempo Real:** Implementação de dashboards de telemetria e interfaces de monitoramento via WebSocket com gráficos interativos e complexos utilizando ECharts.
- **Automação e Integração Industrial:** Configuração de fluxos de dados de chão de fábrica utilizando Node-RED (configurado no fuso horário UTC-3) para comunicação com os equipamentos e processamento lógico.
- **Banco de Dados e Backend:** Modelagem e gerenciamento de banco de dados PostgreSQL utilizando Prisma ORM para persistência segura dos dados de produção.
- **Conformidade de UX/HMI:** Aplicação estrita das normas internacionais de design visual para interfaces homem-máquina industriais (ANSI/ISA-101.01, IEC 60073 e IEC 63303), garantindo a sinalização correta de status das máquinas, níveis de prioridade de alarmes e codificação de ameaças.
- **DevOps e CI/CD:** Planejamento e orquestração de implantações em contêineres utilizando Docker, Docker Compose e proxy reverso Nginx. Automação de pipelines de CI/CD via GitHub Actions com deploy em instâncias AWS EC2, máquinas virtuais locais (Ubuntu Server) e self-hosted runners.
- **IA e Produtividade:** Configuração de fluxos de desenvolvimento locais e offline com assistentes de IA (Antigravity, Continue.dev, Aider e Ollama) integrados ao VS Code no ambiente Ubuntu Linux.
