# Presença online DirectCall

**Cliente:** DirectCall
**Contratante:** DirectCall

## Sobre o projeto

A DirectCall é uma empresa focada em produtos e serviços de telefonia corporativa. Desenvolvi uma identidade visual para seus produtos usando o mesmo template, alterando basicamente cores onde cada produto recebe uma cor predominante, mantendo reservado o vermelho pois é a identidade da empresa. Dessa forma, além de manter a unidade visual, a manutenção fica facilitada. Os sites foram produzidos em HTML, CSS, JavaScript e PHP sem uso de frameworks ou CMS.
