# Docs

**Cliente:** EasyCarros
**Contratante:** EasyCarros

## Sobre o projeto

Contribuí na EasyCarros para a evolução do produto Docs. O serviço verifica órgãos de trânsito, coletando dados sobre multas e débitos automotivos para frotas. Um web crawler capturava os dados, persistindo-os em um banco MongoDB. Uma API RESTful em Node.js fornecia os dados para uma interface em React.js. Foquei na interface gráfica, incluindo UX, e ajudei a padronizar dados no backend para exibição ao cliente.
