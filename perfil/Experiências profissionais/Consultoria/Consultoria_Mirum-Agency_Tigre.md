# Site oficial Tigre

**Cliente:** Tigre - Tubos e conexões
**Contratante:** Mirum Agency

## Sobre o projeto

Sites institucional da marca Tigre. Website produzido em Drupal com templates em HTML, CSS (Sass) e JavaScript (jQuery), possuía catálogo de produtos completo com diversas informações técnicas, integração com a API do Google Maps e páginas institucionais. Ajudei na finalização do catálogo de produtos à serviço da Mirum Agency.
