# Broker One

**Cliente:** Ford
**Contratante:** Mirum Agency

## Sobre o projeto

Website promocional da Troller, marca brasileira pertencente à Ford. Site em PHP usando CodeIgniter com páginas em HTML, CSS (Sass) e JavaScript (jQuery), possuía área de e-commerce de peças, acessórios e produtos promocionais além de informações da competição exclusiva chamada Copa Troller com integração à API do Google Maps. Participei da construção, manutenção e geração de novas features à serviço da Mirum Agency.
